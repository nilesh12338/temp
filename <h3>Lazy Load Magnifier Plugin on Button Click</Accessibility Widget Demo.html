SBI Accessibility Clone Demo

This is a demonstration of the accessibility widget logic built strictly utilizing the jQuery and jQuery UI libraries, with no Bootstrap dependencies.

Try interacting with the widget floating on the bottom left of your screen. Features like Bigger Text, Line Height, and Invert Colors have been implemented.

This is a sample link to demonstrate link highlighting.

You can also Drag the widget around the screen by clicking and holding the top header bar, utilizing jQuery UI's .draggable() function.
